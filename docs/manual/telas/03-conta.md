# Conta (perfil)

Aqui ficam os **dados que identificam o perito** no sistema e no **laudo**.

## Primeiro acesso

No **primeiro acesso**, deve **preencher estes dados por completo**: são os que **qualificam o perito** e **constam no documento do laudo** (nome, vínculo institucional, etc.). Se aparecer um cartão de **boas-vindas** ou mensagem a pedir para completar o cadastro, siga esse passo antes de trabalhar nos atendimentos.

## O que preencher

- **Nome completo**
- **Matrícula**
- **Sexo**
- **Corporação** (lista) — ao escolher, pode aparecer a **unidade pericial**
- **Superior** — hierárquico, quando for obrigatório na sua organização

Revise sempre que algum dado mudar, para o laudo sair correto.

Use **Salvar** no fundo para gravar. **Sair** encerra a sessão.
